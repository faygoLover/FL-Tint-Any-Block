# FL Tint Any Block (`fltint`)

Оттенки и защита для любых поставленных блоков без блок-энтити. Замена укреплённым блокам SecurityCraft, которые лагают
(каждый укреплённый блок — отдельный BlockEntity с владельцем).

Нужен на сервере и на клиенте. Forge 1.20.1.

## Как устроено

- Оттенок = множитель цвета `RRGGBB` (`999999` = 60% яркости, как у SecurityCraft). Светлее текстуры нельзя.
- Хранение: поле в `LevelChunk` → секции 16³: палитра оттенков (до 255 цветов, байт на блок) и бит защиты на блок;
  в сохранении чанка — ключ `fltint`.
- Синхронизация: после пакета чанка (`ChunkWatchEvent.Watch`) — пакет с данными чанка; изменения — пачкой в конце тика тем, кто видит чанк.
- Рендер: Embeddium `BlockRenderer.getVertexColors` (цвета ABGR) и ванильный `ModelBlockRenderer.putQuadData` — цвет квада × оттенок.
- Блок стал воздухом — оттенок и защита снимаются. Смена блока на другой блок оттенок сохраняет.

## Защита

Защищённый блок ломает только ГМ (оператор 2+). Не ломают: игроки (нет даже трещин), взрывы, поршни, мобы
(визер, дракон, эндермен и др.), огонь, моды, ломающие блоки своим кодом. Смена состояния того же блока разрешена
(двери, рычаги, печи работают), смена на другой блок — нет: защищённые блоки «замирают» (трава не станет землёй, медь не окислится).
WorldEdit и команды мода защиту обходят. ГМ с валиком в руке видит оранжевые контуры защищённых блоков (радиус 12); в F3 — строка `fltint`.

## Валик оттенка (только операторы, вкладка «Операторские утилиты» или `/give @s fltint:brush`)

- ПКМ по блоку — покрасить (режим: один блок / плоскость грани / шар, радиус 1–16, «только такой же блок»).
- Shift+ПКМ или колёсико по блоку — пипетка (на укреплённом блоке SC берёт его оттенок).
- ПКМ в воздух — окно: готовые цвета, hex, ластик, режим, радиус.

## Команды (уровень 2)

```
//shade set <цвет> [solid|блок]    выделение WorldEdit; блок — stone_bricks, #minecraft:logs, oak_stairs[half=top]
//shade clear [solid|блок]
//shade convert [цвет]             укреплённые блоки SC → ванильные + тот же оттенок + защита (по умолчанию 999999)
//shade region <от> <до> set|clear|convert ...   то же по координатам, без WorldEdit
//shade get                        оттенок и защита блока под прицелом (hex копируется кликом)
//shade undo                       отменить последнюю покраску/правку защиты (до 5 шагов, до выхода)
//shade colors                     готовые цвета
//shade we [keep|replace]          что делает WorldEdit, ставя блок без оттенка/защиты (по умолчанию replace — снимает)

//protect set [solid|блок]         защитить
//protect clear [solid|блок]       снять защиту
//protect region <от> <до> set|clear ...
//protect undo
```
`/shade` — то же, что `//shade`.

Цвет: имя (`g60`, `reinforced`, `rust`, `soot`, ... — `//shade colors`), 6 hex-цифр (`8C98A8`) или яркость в процентах (`60`).

`solid` — «конструкция, а не мебель»: у коллизии блока хотя бы одна грань закрыта целиком (полные блоки, ступени,
плиты, книжные полки, двери, люки). Не проходят панели, решётки, заборы, стены, мебель на ножках, цветы.
Поправки — теги `fltint:structural` / `fltint:not_structural` (датапак).

`convert` ставит блоки без обновления соседей и без дропа (флаги 2|16|32): факелы, таблички и прочее прикреплённое не отваливается.
Блоки, у которых ванильная версия хранит содержимое (сундук, воронка, раздатчик, кафедра...), пропускаются.
`convert` не попадает в `//shade undo`.

## WorldEdit

Оттенок и защита едут в NBT блока (ключи `fltint:color`, `fltint:protected`) через обёртку `EditSessionEvent`
на стадии `BEFORE_CHANGE`: работают `//copy //cut //paste //rotate //flip //stack //move //undo //redo` и схематики.
Блок без наших ключей (`//set`, `//replace`): `replace` — снимает оттенок и защиту, `keep` — оставляет.

## Ограничения

- Шейдерпаки (Oculus): почти все берут цвет вершин, но какой-то может его игнорировать.
- Конфиг `config/fltint-common.toml`: предел объёма области (`max_volume`), предел записи для отмены.
